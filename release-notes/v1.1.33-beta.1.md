- New (beta): a theme catalogue under Settings > Appearance: Tokyo Night, Dracula, One Dark, Monokai, Nord, Gruvbox Dark, Solarized Dark and Solarized Light. A theme colours the app and the SSH terminal, including its 16 terminal colours
- New (beta): import your own theme from a JSON file. The format is described in docs/theme-format.md
- New (beta): "Keep my SSH terminal colours". With it on, a theme changes only the app and leaves the terminal colours you set
- Light and Dark work as before, and terminal colours can still be changed by hand after picking a theme
- New (beta): seven terminal fonts ship with the app, so they work without installing anything: JetBrains Mono, Fira Code, Source Code Pro, IBM Plex Mono, Roboto Mono, Ubuntu Mono and Hack. All of them have the full Turkish alphabet
- The font picker opens a compact menu that shows each font in itself
- The import and export cards in Settings are the same height, and the font size sits on the slider's line with its value
- The font preview shows a quote with Turkish letters
