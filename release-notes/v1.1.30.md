- New: SFTP file manager for SSH tabs. Right-click a tab and choose SFTP files to see the device's files beside the terminal, and upload or download between them
- The expand button opens it in a window of its own, with this computer's files beside the device's. Shrinking the window brings the panel back
- Paths can be pasted, and the keys work as in File Explorer: a letter jumps to a name, arrows move, Enter opens, Backspace goes up
- New: ChatGPT Work through MCP (Settings > MCP integration). Off by default, only for connections you allow one by one, under anonymous names, and every command asks you first. Terminal output is sent to the agent as it is
- New setting: Receive beta updates (Settings > Updates)
- Updates are checked every five minutes while the app is open
