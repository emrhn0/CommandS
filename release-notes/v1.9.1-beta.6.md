- On macOS, Remote Desktop now opens inside its tab, as it does on Windows, instead of in a separate app. No other RDP client is needed
- The remote desktop takes the size of the tab and follows it when the window or a split pane is resized
- Cmd+C, Cmd+V and other Cmd shortcuts act as Ctrl on the remote side; Cmd pressed on its own opens the Start menu. Ctrl+Alt+Del is in the tab's right-click menu
- Copied text goes both ways between the Mac and the remote desktop
- A connection with no saved password asks for it inside the tab; what you type is used for that tab only and never saved
- A session that fails or ends is never retried on its own, so a wrong password cannot lock the account; reconnect with the button in the tab
