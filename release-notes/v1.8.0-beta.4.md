- The yes/no question some devices ask at login (a Palo Alto banner, for one) can be remembered: answer Yes with Remember ticked, and from then on the connection says yes and logs in with its saved password by itself. It can be turned off in the connection's settings
- SFTP: select several files with Ctrl and Shift and transfer them in one go
- Switches: a connection can keep an enable password, encrypted like the login password. After you type enable, CommandS offers to fill it in at the password prompt
- Fix: in Turkish, the restore button in Backups read "Önceki boyut" (the window's button). It now reads "Geri yükle"
