- Telnet connections: pick Telnet in New Connection, Edit Connection or the quick connect bar (port 23 by default). Log in at the device's own prompt. Telnet is not encrypted, and the tab says so. On a Mac it needs the `telnet` command-line client
- Clone now opens the copy straight in Edit Connection. Cancel keeps the copy as it was cloned
- A warning appears under a password that starts or ends with a space. The password is still saved exactly as typed
- MCP: agents can create folders and save up to 100 SSH or RDP connections at a time. CommandS shows what will be added and saves nothing without your approval. Saving a connection does not give the agent access to it
- MCP: opening the same connection again reuses the agent's open tab instead of opening another one. `list_sessions` lists the agent's open tabs, and `new_session` opens a separate one
- MCP: connection IDs are shorter (such as `a4`). Older `DEVICE-…` IDs still work
- MCP: the server port can be changed in Settings > Privacy. Open sessions stay connected
