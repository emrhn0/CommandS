- Backups of your connections: one every day, and one before every import, delete or restore. The newest 30 daily and 20 others are kept, with passwords still encrypted. Settings > Connections > Backups lists them and restores one with a click. If your saved connections ever cannot be read, nothing is saved over them, and the app offers to restore a backup
- Search in a terminal: the magnifier at the top right of a session, or Ctrl+Shift+F. Every match is marked; Enter and the arrows move between them, Esc closes it
- Type into several sessions at once: in Split View, tick the panes on their bars. What you type into one ticked pane goes to all of them
- Credential profiles: one user name and password for many connections, so a changed password is changed once (Settings > Connections, or a connection's Credentials)
- Favorites: star a connection from its menu. Favorites have their own place on the welcome panel
- Quick search: the magnifier in the title bar, or Ctrl+K (Ctrl+Shift+K inside a terminal). Find any connection or folder by name or address
- Sort menu on the selection bar: name A–Z, name Z–A, IP address (numeric order) or device type. A folder can be sorted from its own menu with Sort contents
- Switches: a connection can keep an enable password, encrypted like the login password, and CommandS offers it at the enable prompt
- The yes/no question some devices ask at login can be remembered, so the connection logs in by itself
- SFTP: select several files with Ctrl and Shift and transfer them in one go
- Record session asks every time whether to include what is already on screen ("Include history")
- Choice fields open a compact menu just below the field, in the theme's colours
- When a device's SSH key has changed, a bar says so in plain words and can forget the old key and connect again
- Security: Remote Desktop remembers each server's key (Windows) or certificate (macOS) and refuses or asks if it changes, so an impostor does not receive the saved password
- Security: an AI agent connected over MCP can no longer hide control characters in a "show" command to run something else; commands with $( ) always ask, and the MCP address is replaced if another program holds its port
- Security: SSH host keys are saved correctly when the Windows user folder has a space in its name, and the password helper no longer passes the server's prompt to the command prompt
- Security: SFTP downloads skip files whose names would land outside the chosen folder
- Exports leave passwords and credential profile links out unless you tick the lock next to a connection; an imported connection moved to another host no longer keeps its password
- macOS: a password copied for Microsoft's Remote Desktop client is cleared from the clipboard after 30 seconds
- Fix: a Remote Desktop session could stay in front of a dialog and hide it
- Fix: very large cursor moves from a device could freeze a session log
