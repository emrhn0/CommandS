- Security: an AI agent connected over MCP can no longer slip a hidden control character (such as Ctrl+U or Backspace) into a "show" command to run something else without your approval. Commands with control or invisible characters are refused, and commands with $( ) always ask
- Security: if another program already holds the MCP port, the MCP address is replaced, so an old address can no longer be used
- Security: Windows Remote Desktop now remembers each server's key the first time and refuses to log on if it changes later, so an impostor does not receive the saved password
- Security: SSH host keys are now saved correctly when the Windows user folder has a space in its name. Before, a changed host key could go unnoticed
- Security: the Windows password helper no longer passes the server's login prompt to the command prompt
- Security: SFTP downloads skip files whose names would land outside the chosen folder
- Exports leave passwords, enable passwords and credential profile links out unless you tick the lock next to a connection
- Importing a Remote Desktop Manager file that moves a connection to another host no longer keeps its saved password; importing without passwords also drops credential profile links
- macOS: the .rdp file for Microsoft's client can no longer carry extra settings from an imported name, and the client now warns about a server it cannot verify
- Session logs: very large cursor moves from a device can no longer freeze the app
- Record session now asks, every time, whether to include what is already on screen ("Include history"); the box always starts unticked
