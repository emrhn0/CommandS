- Only connections you allow one by one (right-click a connection) are offered, under anonymous names such as DEVICE-01. Real names, addresses and passwords are never sent
- Every command asks you first. Nothing runs without Run; no answer within two minutes counts as no
- Terminal output is sent to the agent as it is, so it can still show device names and addresses
