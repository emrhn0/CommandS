- Command palette: Ctrl+Shift+P lists the app's commands with their shortcuts. Find one by typing, choose with the arrows and Enter
- New commands for the session in front: copy its connection name, host address or saved password, and type the saved password into an SSH session without pressing Enter
- Settings > Hotkeys: give any command a shortcut, remove one or put the default back. A shortcut already in use is refused
- Recently opened: a name like "DEVICE-01 - 192.0.2.30" shows the name on the left and the address in the right column, like the others. A custom port shows beside the address
- A hidden connection list keeps the Settings button, just above the button that brings the list back, and shows the CommandS mark at the top (with a small ß tag on betas)
