- New: drag tabs along the tab bar to reorder them, as in a browser
- New: drag a tab to the edge of a session to split the view, with a frosted preview of where it will land
- New: while dragging a tab, pick a layout from the bar at the top and drop it into the pane you want
- New: drag connections in the list to put them in any order; the order is kept
- Security: remembered passwords are now stored encrypted, with a key held by Windows or the macOS Keychain. Existing passwords are converted on the first start
- Note: exports still contain passwords in readable form, and moving saved settings to another computer without an export means entering passwords again
- Better Cisco detection: switches that name no maker at login are recognised from their configuration output, and slow devices get more time to identify themselves
