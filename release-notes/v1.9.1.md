- On macOS, Remote Desktop opens inside its tab, as on Windows, with no other RDP client needed. It follows the size of the tab, Cmd shortcuts act as Ctrl on the remote side (Cmd alone opens the Start menu), copied text goes both ways, and a connection with no saved password asks for it in the tab without saving it
- Command palette: Ctrl+Shift+P lists the app's commands with their shortcuts; type @ and a name or address to open a saved connection
- New commands for the session in front: copy its name, address or saved password, or type the saved password into an SSH session
- Settings > Hotkeys: give any command a shortcut, remove one or put the default back
- A home button at the start of the tab bar brings back the welcome screen while your sessions keep running, with cards for your connections, open sessions and folders, and the most useful shortcuts
- Folders can have a colour (a folder's menu, Color…), shared by the folders inside it and the tabs of its connections
- A thin status bar under the session in use shows its protocol, its address (click to copy) and how long it has been open
- Tabs are rounded pills, the one in use filled with the accent colour
- The connection list's header is lighter, with a small New button; a waiting update shows as a green note beside it
- New theme choice, Same as system: CommandS Dark or Light, following your computer's dark or light mode. New light theme, Sakura
- Recently opened connections show the address in the right column, with a custom port beside it
- A hidden connection list keeps its Settings button
- Importing a file without passwords no longer wipes the passwords this computer remembers for the same connections
- Exporting a connection that uses a credential profile now includes its user name (and its password, when passwords are exported), so it can log in on another computer
- Connections and folders that pointed at a missing folder, or folders nested inside one another in a loop, were saved but never shown in the list; they now appear at the top level
- XML export keeps everything JSON does: folder colours, device types, saved layouts and the login question answer. Saved layouts drawn by hand keep their shape when exported
- Deleting a saved layout takes a backup first, like other deletions
- An update is installed only after its checksum has been verified; if the checksum cannot be read, the update stops instead of going ahead
