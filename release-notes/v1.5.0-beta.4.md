- Split View: a pane left empty when you apply a layout now stays empty, as a place to drop a tab later, instead of the pane next to it growing over it. Drag a tab from the tab strip onto it, or close it with its x
- Split View window: a tab in a short pane (a layout with many rows) shows its name on one line instead of being cut off
- Connection list: right-click a folder, Open all connections opens every connection in it and in the folders inside it. A folder further down opens only its own
