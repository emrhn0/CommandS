- Sorting is clearer: the selection bar has one Sort menu that names each order (name A–Z, name Z–A, IP address, device type) instead of unlabeled buttons
- A folder can be sorted without selecting anything: right-click it (or use its ... menu) and choose Sort contents. Sorting by name also orders its subfolders
- New orders: name Z–A, and device type (connections of unknown type go last)
- The selection bar's select-all button is now a checkbox that shows whether all, some or none are selected
